  │  └ nonVeg       │ Integer    │ Number of non-veg meals (300 INR each)       │
  └─────────────────┴────────────┴──────────────────────────────────────────────┘

  Available Test Data (from DB):
  ┌──────────┬─────────────┬──────────────────────┬───────────────────────────┐
  │ FlightId │ cabinClass  │ Available Seats       │ Base Price (per pax)      │
  ├──────────┼─────────────┼──────────────────────┼───────────────────────────┤
  │ F101     │ Economy     │ 1B, 1C               │ 4500 INR                  │
  │ F101     │ Business    │ 1B, 1C               │ 12000 INR                 │
  │ F102     │ Economy     │ 1C                   │ 3200 INR                  │
  │ F103     │ Economy     │ 1A, 1B, 1C           │ 15000 INR                 │
  │ F103     │ Business    │ 1A, 1B, 1C           │ 45000 INR                 │
  └──────────┴─────────────┴──────────────────────┴───────────────────────────┘

  Note: Run this SQL to reset seats if already Booked:
  UPDATE seats SET seat_status = 'Available'
  WHERE schedule_id = 1 AND seat_number IN ('1B', '1C');

────────────────────────────────────────────────────────────────────────────────
  PRICING FORMULA
────────────────────────────────────────────────────────────────────────────────

  baseAmount  = base_price  × number of passengers
  seatExtra   = SUM(seat.extra_price)  for each selected seat
  mealCost    = (veg × 200) + (nonVeg × 300)
  subtotal    = baseAmount + seatExtra + mealCost
  tax         = ROUND(subtotal × 12%)
  totalAmount = subtotal + tax

  Example with F101 Economy, 2 pax, seats 1B+1C, 1 veg + 1 nonVeg:
  ┌─────────────┬─────────────────────────────────────────────┐
  │ baseAmount  │ 4500 × 2             = 9000 INR             │
  │ seatExtra   │ 2000 + 2000          = 4000 INR             │
  │ mealCost    │ (1×200) + (1×300)    = 500  INR             │
  │ subtotal    │ 9000 + 4000 + 500    = 13500 INR            │
  │ tax (12%)   │ 13500 × 0.12         = 1620 INR             │
  │ totalAmount │ 13500 + 1620         = 15120 INR            │
  └─────────────┴─────────────────────────────────────────────┘
